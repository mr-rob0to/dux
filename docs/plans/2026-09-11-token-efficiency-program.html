Goal

Skip planning for obvious work, use Sonnet for bounded implementation, run one Dux-managed Claude worker, trim unused worker surfaces, and move security review to qualified Codex.

Rejected scope

No usage database, allowance scheduler, pause/resume state machine, operator accounting, plan-page generator, benchmark system, or mechanical /ship rewrite.

Approach

Keep the existing plan, ship, and scout shapes. Dux uses a short planning checklist. Scripts enforce a stored bounded|complex risk and paired plan fields.

A plan-free task still completes the unchanged build, test, correctness review, security review, pull request, and CI gate. A second worker is refused before worktree creation. The security selector changes only after one fixture qualification passes.

Defaults and hard constraints

Assumptions

  • All dispatched workers currently use Claude.
  • Missing risk on a legacy task means complex.
  • External Claude sessions and devices stay outside Dux's view.
  • An explicit request for a plan always wins.

Constraints

  • Bash 3.2 and existing dependencies only.
  • No new task shape, scheduler, or classifier call.
  • Every new assertion is broken and seen to fail.
  • /ship, both reviews, CI, and operator-only merge remain.
  • No AI attribution in GitHub or commit text.

Risks

  • Wrong bounded choice: named plan triggers fail closed, and the full ship gate remains.
  • Stuck worker: later starts wait for existing recovery and an operator retry.
  • CLI flag mismatch: qualify the installed Claude CLI before adapter changes.
  • Thin security evidence: the one-run limit is explicit; automated requalification is deferred.
